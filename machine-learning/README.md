# Machine learning

This directory has code for the machine learning models used in the project. The code is used to test the models and choose the correct parameters.

`SARIMA.py` has a (unfinished) class that is meant to make testing the models and tuning the parameters easier.

`test_SARIMA.py` is spaghetti code that demonstrates how the SARIMA model and the Rolling Forecast Origin can be calculated and plotted.
